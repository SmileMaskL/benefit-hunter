## 왜 이 주제인가

세 가지 조건("전 연령대가 검색함", "매일 다시 올 이유가 있음", "경쟁자와
확실히 다름")을 동시에 만족하는 니치를 기준으로 골랐다.

| 조건 | 이 주제가 왜 맞는가 |
| --- | --- |
| **전 연령대가 찾는 주제** | 대학생·취준생(장학금·인턴), 청년(주거·구직·창업), 신혼부부(출산·보육), 자영업자·소상공인(전 연령), 예비창업자, 중장년(재취업), 농어민·문화예술인까지 — "지원금·지원사업"은 나이·직업과 무관하게 검색량이 꾸준한 몇 안 되는 카테고리다 |
| **매일 다시 올 이유** | 정부·지자체 공고는 **매일 새로 올라오고, 마감일이 매일 하루씩 줄어든다.** "오늘 마감 3일 남은 공고가 뭔지"는 어제 본 사람도 오늘 또 봐야 하는, 태생적으로 데일리 소비 콘텐츠다 |
| **명확한 차별점** | 지원사업 공고는 부처·지자체·공사별로 **최소 20개 이상 사이트에 파편화**되어 있다(기업마당, K-스타트업, 온통청년, 복지로, 각 광역·기초자치단체 홈페이지 등). 이걸 매일 손으로 모아 정리하는 사람이 거의 없다는 점 자체가 진입장벽이자 우리의 해자(moat)다 |

일반적인 "청년 정책 뉴스레터"들은 청년 카테고리 하나만 다루고 주 1~2회
발행하는 경우가 많다. 이 프로젝트는 **소상공인·창업·청년을 한 번에 다루고
매일 발행**하며, 아래처럼 "마감 임박순 정렬 + 조건 필터"로 한 단계 더
들어간다.

## 차별화 포인트

| 차별화 포인트 | 무엇이 다른가 |
| --- | --- |
| **마감임박 D-day 정렬** | 단순 신규 공고 나열이 아니라, 마감일이 가까운 순으로 정렬해서 "오늘 안 보면 놓친다"는 긴급성을 매일 만들어낸다 (`예산 소진시까지`인 공고는 별도 경고 표시) |
| **세그먼트 태그** | 모든 공고에 `[청년][소상공인][예비창업][지역:OO]` 태그를 달아, 독자가 자기 조건에 맞는 것만 3초 안에 스캔하게 한다 |
| **행정용어 번역** | 공고 원문의 애매한 행정 문구를 "누가 받을 수 있고, 얼마를 받고, 뭘 준비해야 하는지" 3줄 요약으로 바꿔준다 |
| **크로스 소스 통합** | 기업마당(중기부) + K-스타트업(창업진흥원) + 온통청년(청년정책) 등 서로 다른 부처 소스를 하나의 발행물로 합친다 — 개별 사이트 알림 서비스는 자기 부처 것만 알려준다 |
| **salary-calculator 시너지** | `D:\Lee\salary-calculator`(연말정산·육아·퇴직·재산세 계산기) 방문자는 정확히 이 뉴스레터의 타겟과 겹친다. 계산기 결과 페이지에 "당신에게 맞는 지원금도 놓치지 마세요" CTA를 붙이면 별도 마케팅비 없이 구독자를 확보할 수 있다 |
| **유료 전환 시 마감 리마인더** | 관심 등록한 공고의 마감 D-3에 별도 알림을 보내는 기능은 `seller-monitor` 프로젝트에서 이미 검증한 "직접 입력 + 리마인더" 신뢰성 철학과 동일한 패턴이다 — 외부 API 의존 없이 확실히 동작한다 |

## 실행 로드맵

1. **0주차 (지금)**: [AUTOMATION.md](AUTOMATION.md)의 계정 설정(GitHub 저장소·Pages·Brevo) 완료, 브랜드명·구독 폼 준비
2. **1~4주차**: 자동 발행 확인(주 5회, GitHub Actions가 대신 실행), salary-calculator에 구독 CTA 삽입, 목표 구독자 300명
3. **5~8주차**: 오픈율 안정화(목표 35%+), 구독자 500~1,000명 도달 시 [MONETIZATION.md](MONETIZATION.md)의 유료 티어 오픈 검토
4. **이후**: 유료 전용 맞춤 필터·마감 리마인더 도입, 지자체 소스 확장

## 브랜드명 — 지원금헌터

"최대한 많은 사람이, 최대한 자주 찾아오게" 만드는 것을 기준으로 고른
이름이다. 후보들과 비교하면 다음과 같다.

| 후보 | 왜 채택/탈락했나 |
| --- | --- |
| **지원금헌터** (채택) | "헌터(사냥꾼)"는 나이·성별과 무관하게 전 세대가 아는 보편적 비유고, "꿀템헌터·알바헌터"처럼 **"부지런히 찾아다니면 이득을 챙긴다"는 국내에서 이미 검증된 네이밍 패턴**이다. 매일 새 사냥감(신규 공고)이 올라온다는 뉘앙스가 "매일 다시 찾아온다"는 습관 형성과 자연스럽게 붙는다. 검색 시 "지원금헌터"라는 고유 단어로 브랜드 검색(브랜드 SEO) 점유가 쉽고, 유사 서비스명과 겹치지 않는다 |
| 지원금 줍줍 | "줍줍"(청약 줍줍, 주식 줍줍)은 화제성·공유 욕구는 가장 강하지만 20~30대 커뮤니티 은어에 가까워 중장년·노인 독자에게는 즉시 와닿지 않을 위험이 있다. 인스타/커뮤니티 홍보용 부제("오늘의 지원금, 줍줍하세요")로는 계속 활용 |
| 지원금레이더 | "레이더"는 "탐지"는 표현하지만 능동적으로 "매일 다시 온다"는 습관 트리거가 약함. 정적인 느낌 |
| 오늘의 지원금 | "오늘의 OO"는 데일리 습관 포맷으로는 검증됐지만(오늘의집 등), 고유명사성이 약해 브랜드로 검색되기보다 일반 검색어에 묻히기 쉬움 |

**공식 브랜드명: 지원금헌터** / 부제(태그라인): "매일 아침, 마감임박
지원금을 대신 사냥해드립니다" / 캐주얼 공유 문구: "오늘 뭐 떴나 줍줍하러
가자" (SNS·커뮤니티 공유 시 후킹용으로 "줍줍" 표현을 부제로 병행 사용)

도메인/카카오톡 채널명은 `지원금헌터` 그대로 확보하는 것을 권장 —
`jiwonhunter` 계열로 영문 표기 통일.

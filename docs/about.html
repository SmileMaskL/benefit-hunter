지원금헌터 소개

왜 만들었나요?

정부·지자체 지원사업은 매일 새로 올라오지만, 공고가 여러 사이트에 흩어져 있고 마감도 제각각입니다. 바쁜 소상공인과 예비창업자가 매일 여러 사이트를 돌아보기는 어렵고, 그러다 보면 자격이 되는 사업을 마감 뒤에야 알게 됩니다. 지원금헌터는 "오늘 꼭 봐야 할 공고"를 한 페이지로 모아, 놓치는 지원금을 줄이기 위해 만든 무료 서비스입니다.

어떻게 운영되나요?

  • 데이터 출처: 중소벤처기업부의 기업마당(bizinfo.go.kr)과 창업진흥원의 K-Startup(k-startup.go.kr)에 공개된 공고만 사용합니다. 출처가 불분명한 정보는 싣지 않습니다.
  • 매일 자동 갱신: 매일 아침 자동화 프로그램(GitHub Actions)이 새 공고를 모으고, 이미 마감된 공고는 빼고, 마감이 가까운 순서로 정렬해 발행합니다.
  • 분류: 공고 제목과 기관명을 바탕으로 예비창업·소상공인·청년 같은 대상과 지역을 자동으로 태그합니다. 자동 분류라 실제 자격과 다를 수 있으므로 원문 확인이 필요합니다.
  • 지난 발행 보관: 매일 발행분은 아카이브에 날짜별로 남아 있어 키워드로 검색할 수 있습니다.

이용 시 주의할 점

  • 지원금헌터는 공고를 모아 보여 주는 안내 서비스이며, 정부·지자체나 주관 기관과 관계가 없습니다.
  • 신청은 각 공고의 원문 사이트에서 직접 진행해야 합니다. 지원금헌터는 신청 대행이나 선정과 관련된 어떤 요청도 하지 않습니다.
  • 공고 내용이 바뀌거나 조기 마감될 수 있으니 최종 정보는 항상 원문에서 확인하세요.
  • 처음이라면 신청 가이드에서 공고 읽는 법과 사기 구별법을 먼저 읽어 보세요.
